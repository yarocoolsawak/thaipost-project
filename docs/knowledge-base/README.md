## ขอบเขตล่าสุด (ณ 22 ต.ค. 2569)

ใช้ข้อมูลส่วนนี้ก่อนข้อเท็จจริงเก่าด้านล่าง ถ้าขัดกัน

**ระยะแรก**
- เฉพาะ MyOrder, Automation ตามกติกา + API, **ไม่ใช้ AI**
- เริ่มทดลองที่**สถานะเร็วขึ้น**และ**ภาพนำจ่าย**ก่อน

**เป้าหมาย**
- **ระบบ 70% / คน 30%** วัดจากเวลางานคนที่ลดลงเทียบค่าตั้งต้น ต้องพิสูจน์ด้วยการทดลอง

**งานในอนาคต (ยังไม่อนุมัติ)**
- ระบบสร้างใบงาน
- เปิดให้พาร์ทเนอร์อื่น
- พิกัด, ข้อมูลเหตุผิดปกติภายใน
- Handheld (ตอนนี้เน้นสแกน ส่งหรือตอบข้อความไม่ได้)
- เคลม / COD

**SLA**
- แยกเวลาขนส่งออกจากเวลาตอบเคส
- ทีมเทคโนโลยีพูดถึงนับจาก**รับฝาก** ส่วนดูงานเดิมใช้หลัง**เปิดถุง** ยังต้องยืนยัน
- ค่า 3 วันไม่ใช่ค่ากลางทุกพาร์ทเนอร์

**กติกาเคส**
- สถานะเคสแยกจากสถานะพัสดุ
- ส่งต่อสำเร็จ / ตอบเรื่อง / ปิดเคส เป็นคนละผลลัพธ์
- นำจ่ายสำเร็จอย่างเดียวไม่ใช่เงื่อนไขปิดเคสอัตโนมัติ

**ตัวเลขที่ใช้นำเสนอ** (ตัวอย่างอธิบายแนวคิด ยังไม่ยืนยัน)
- ฐาน 4 ราย 310,000 ชิ้น/วัน → ×4 = 1,240,000
- 1,000 เคส ต่อพัสดุ 50,000 ชิ้น
- ระบบช่วยได้ 500 เคส: ติดตาม SLA 20% + ขอภาพ 30%
- คนทำได้ 30 เคส / คน / วัน
- BOT เดิมใช้ได้ประมาณ 10 วันต่อเดือน (Token)

## ข้อเท็จจริงที่ใช้บ่อย

**ปริมาณงานและผู้เกี่ยวข้อง** (ครั้งที่ 1)
- ประมาณ 1,000 เคส/วัน หรือ 30,000 เคส/เดือน
- บริษัทคู่ค้าประมาณ 50 บริษัท
- กลุ่ม CEC 14 กลุ่ม

**ระบบที่ใช้ตอนนี้**
- LINE: รับเรื่องและประสานงาน
- Excel: บันทึกเรื่อง
- QMS: สถานะพัสดุ
- DPost/eParcel: ข้อมูลพัสดุและไปรษณีย์ปลายทาง
- โทรศัพท์: เคสเร่งด่วน

**ประเภทเคส** (ครั้งที่ 2)
- เร่งนำส่ง (มากที่สุด)
- แจ้งปิดงาน
- นำจ่ายใหม่
- แจ้งตีกลับ

**เกณฑ์ระยะเวลา** (ครั้งที่ 2 ยังต้องยืนยัน)

| เงื่อนไข | ระยะเวลา |
|---|---|
| หลังเปิดถุง ภายในภาคหรือกรุงเทพฯ | 1–2 วัน |
| หลังเปิดถุง ข้ามภาคหรือข้ามจังหวัด | 1–3 วัน |
| พื้นที่ห่างไกล | 3–5 วัน |
| หลังเปิดเก็บรอผู้รับติดต่อ | 7 วัน แล้วตีกลับต้นทาง |

**เกณฑ์ประสานสาขา** (ครั้งที่ 1): ครบหรือเกิน 3 วัน ยังต้องยืนยันว่าเป็นเกณฑ์เดียวกับหลังเปิดถุงหรือไม่

**เงื่อนไขปิดเคส:** สถานะ "นำจ่ายสำเร็จ" อย่างเดียวยังไม่พอให้ปิดเคสอัตโนมัติ ต้องมีหลักฐานชัดเจนและเจ้าหน้าที่ตรวจ

**ข้อมูลที่ MyOrder ยังไม่เห็น**
- ภาพหลักฐานนำจ่าย
- เหตุผลประกอบสถานะ เช่น เหตุผลที่ผู้รับปฏิเสธ

**ข้อจำกัดการโทร**
- พนักงานนำจ่ายรับสายไม่ได้ขณะขับรถ
- ผู้รับไม่รับเบอร์แปลกเพราะกลัวมิจฉาชีพ
- จึงต้องบันทึกผลการติดต่อและนัดติดตามซ้ำ
